About Heresy Editor

Heresy Editor is a map editor for the classic DOOM games, and a few related games such as Heretic, Hexen and Strife. This fork is focused on map authoring and testing for BiasedDoom. The supported operating systems are: Linux (and other Unices), Windows and macOS.

Heresy Editor is free software under the GNU General Public License (GPL). Please note that it comes with absolutely NO WARRANTY of any kind.

History

It started when the Yadex editor was ported to a proper GUI toolkit, namely FLTK, and implemented a system for multi-level Undo / Redo. These and other features have required rewriting large portions of the existing code, and adding lots of new code too. That program became Eureka Editor; Heresy Editor now continues from it as a BiasedDoom-focused fork.

See the Credits page for more information / copyrights.

Features

  • Undo/Redo (multiple levels)
  • 3D preview
  • Low system requirements
  • Editable panels for things, linedefs, sectors (etc)
  • Smart Door and nonmodal Smart Sector authoring for rooms, corridors, stairs, lifts, and door-aware connections
  • Browser for textures, flats, things (etc)
  • Key binding system
  • Built-in nodes builder
  • WAD and PK3 projects with validated multi-map campaign graphs
  • Campaign reachability, cycle, and missing-target diagnostics
  • Versioned multi-entry episode and hub campaign modeling
  • Read-only PK3 declaration and resource inventory

Supported Games

  • DOOM
  • DOOM 2
  • Final Doom
  • FreeDoom
  • HacX
  • Heretic
  • Hexen
  • Strife

Target Engine

BiasedDoom is the primary engine target. Select the biaseddoom source-port profile; Test in Game automatically searches for BiasedDoom or GZDoom, including extensionless Linux builds, with responsive progress and cancellation for deep searches.

Requirements

  • 128 MB of computer memory
  • 800x600 or higher screen resolution
  • a keyboard and a two-button mouse
  • the data (IWAD) file from a supported game (DOOM etc)
