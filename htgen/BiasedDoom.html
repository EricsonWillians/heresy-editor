BiasedDoom Integration

BiasedDoom is the primary target engine for Heresy Editor. It is derived from GZDoom and retains the Doom-family command-line and map-format interfaces used by the editor.

Current Workflow

  1. Open File / New Project or File / Manage Project.
  2. Select the game IWAD.
  3. Select zdoom as the Source Port.
  4. Use the port setup button or Tools / Test in Game and select the biaseddoom executable.

A typical local development build in this workspace is ~/workspace/BiasedDoom/build/biaseddoom. Heresy Editor supplies -iwad, -file and -warp arguments when it launches the engine.

Compatibility Boundary

The current zdoom profile covers inherited ZDoom map formats, things, action specials and dynamic lights. It does not yet promise editor metadata for every BiasedDoom-only actor or extension. Dedicated BiasedDoom definitions remain an active compatibility goal.

Heresy Editor currently edits WAD maps and resources. BiasedDoom can load additional PK3 resources when they are supplied separately to the engine.
