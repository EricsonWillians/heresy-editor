# Heresy Editor 2.7.0

Heresy Editor 2.7.0 makes creating sectors with the mouse direct and
intuitive: drag out rectangular sectors straight on the canvas, or trace
freehand outlines point by point, with no dialog and no mode juggling.
It also simplifies the grid-snap mouse indication.

## Quick sector drawing

* Rectangle draw: in Sector mode, dragging the left mouse button on
  empty space now draws a rectangular sector with a live preview and
  creates it the moment the button is released, as a single Undo
  operation. The rectangle follows the grid, including rotated and
  oblique mathematical-grid axes. SHIFT-drag keeps the classic
  selection box, and a plain click still clears the selection.
* Freeform draw: press F in Sector mode (or Sector Operations →
  "Draw sector (freeform)") and click to place outline points. Points
  snap to existing vertices — even off-grid, so outlines attach exactly
  to existing sectors — and otherwise to the grid; SHIFT constrains
  each segment to 45-degree steps. Click the first point or press ENTER
  to close the shape and create the sector; right-click removes the
  last point, ESC cancels.
* Both gestures work in the void and attached to existing sectors:
  walls are reused or split, shared edges become two-sided, and the new
  sector inherits neighboring properties — exactly as if the lines had
  been drawn by hand. Each gesture commits through the same
  closed-loop insertion path used by the Smart Sector Designer.

## Snap indication

* The grid-snap mouse indication no longer draws a guide line from the
  raw pointer to the snap target. The snap reticle is now simply a
  compact haloed diamond on the exact target, rendered above map
  geometry.

## Documentation
