# Heresy Editor 2.1.1

This is the first tagged release of the BiasedDoom-focused fork.

## Fork identity and discovery

* Renamed the product, application, executable, desktop integration, manual,
  packages, and current documentation to Heresy Editor and `heresy`.
* Added efficient, bounded IWAD discovery for normal per-user and system
  locations, Steam libraries and manifests, GOG layouts, environment paths,
  and the Linux `~/.steam/debian-installation` layout.
* Preserved inherited Eureka configuration paths and WAD identifiers only where
  changing them would break existing projects or settings.

## Distribution

* Added tested Linux x86_64 and arm64, Windows x86 and x86_64, and macOS x86_64
  and arm64 packages with SHA-256 checksums.
* Added CodeQL analysis and tag-driven publication as an actual GitHub Release.

## Inherited improvements since Eureka Editor 2.1.0

* Allowed linedefs to have both mapped and secret flags.
* Fixed a fatal error when loading DEHACKED lumps with unnamed thing entries.
* Fixed a rare crash involving the thing-browser category selector.
* Fixed WAD-save endianness and aarch64 execution problems.
* Raised the minimum supported macOS version to 10.15.
