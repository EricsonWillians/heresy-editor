# Heresy Editor changelogs

Heresy Editor inherits the release history in this directory from Eureka
Editor. Those files preserve the names, paths, identifiers, and behavior of the
releases they originally documented; references to Eureka Editor in them are
historical rather than current branding.

New fork-specific changelogs should use the Heresy Editor name and describe the
state of BiasedDoom compatibility when relevant.

The current release notes are [Heresy Editor 2.7.0](2.7.0.md).
