# Heresy Editor 2.4.0

Heresy Editor 2.4.0 makes project textures and large-map construction
first-class authoring workflows. It also doubles the practical architecture
catalog while preserving the review-first, one-operation editing model.

## Surface texture import

* Added a multi-file Surface Texture Importer for PNG, JPEG, TGA, Doom patch,
  and traditional raw-flat resources.
* Imports can target walls, floors/ceilings, or both. Reviewed WAD writes use
  isolated texture and flat namespace markers; PK3 writes retain explicit
  `textures/` and `flats/` destinations.
* Added decoded thumbnails, intrinsic dimensions, transparency and format
  reporting, safety limits, exact package destinations, and batch-wide
  validation before any package change.
* Added complete loaded-order conflict diagnostics across IWADs, external
  resources, and the project. Rename, intentional Override, unambiguous
  Replace, and Skip policies never silently truncate, shadow, or overwrite a
  resource.
* Imports use a backed-up atomic package replacement, then refresh only image
  catalogs and rendering caches. Map selection, dirty resident documents,
  canvas position, project metadata, and complete Undo/Redo histories remain
  intact.
* Imported resources become immediately available to wall, floor, ceiling,
  Smart Door, and Smart Sector selectors. Their real pixel dimensions drive
  the same tiling, pegging, offset, split-correction, and alignment paths as
  IWAD images.

## Texture fit, scale, and alignment

* Added Surface Texture Transform for selected or highlighted wall, floor, and
  ceiling surfaces, available from the Edit menu, object panels, 3D view, and
  `Alt+T`.
* Added exact and relative panning, proportional native/64/128/256 sizing,
  mirroring, plane rotation, and Hammer-style Fit Both, Fit Width, and Fit
  Height using each target's real geometry.
* Every numeric value has holdable coarse/fine step controls. The independent,
  resizable review window maintains an always-live reversible canvas preview.
* ZDoom/BiasedDoom and Eternity UDMF maps store declared per-surface
  transformations directly. Modern-port Doom and Hexen projects can create
  safely named fitted project resources when their binary map format cannot
  serialize scale.
* OpenGL and software rendering, UDMF load/save, wall alignment, and one-step
  map Undo/Redo share the same transform model.

## Mathematical construction and inspection

* Added a live Mathematical Grid & Snapping tool with 30 orthogonal,
  proportional, rotated, oblique, triangular/hexagonal, projection, and polar
  geometry presets.
* Added 75 grouped spacings for Doom architecture, large maps, decimal
  engineering, Fibonacci values, and powers of three, plus arbitrary whole
  steps from 1 through 65,536.
* Added editable primary/secondary spacing, pivot origin, rotation,
  inter-axis angle, polar divisions, major interval, and nearest/lower/upper/
  toward-origin/away-from-origin rounding.
* Drawing, object insertion, movement, paste, Quantize, and Smart Sector
  gestures now use the same mathematical intersections. Smart Rooms follow
  rotated and oblique construction axes.
* Hardened document bounds, subdivision bounds, canvas clipping, and
  coordinate display for large positive UDMF coordinates.
* Added `Shift+Tab` whole-linedef 3D inspection with exact prior mode,
  selection, overlay, and error-state restoration. `Shift+F8` and
  `Ctrl`/`Cmd+F8` cycle all 2D rendering overlays and 3D in either direction.

## Expanded architecture library

* Expanded Smart Sector Architecture from 28 to 58 real sector generators,
  adding five structures to each established family.
* New supports include cross cores, accessible tower shells, buttressed
  towers, paired shear walls, and stepped monument plinths.
* New walkable structures include lift-capable platforms, split stages,
  mirrored terraces, podiums, amphitheaters, switchback and ceremonial stairs,
  spiral stairs, catwalks, and crossing bridges.
* New environmental structures include moats, canals, cascades, fountain
  courts, partitions, crenellated and buttressed walls, privacy screens,
  gatehouses, tray/barrel/cross vaults, domes, and beam lattices.
* Structure-specific metadata now drives controls, safe defaults, mirroring,
  semantic roles, effects, and optional Smart Lift behavior without relying
  on enum ordering or misleading style substitutions.

## Preservation and quality

* Surface operations revalidate source files, packages, resources, and map
  targets at apply time and fail atomically when reviewed state is stale.
* Existing offsets, pegging, unrelated flags, extended UDMF properties,
  specials, project resources, and package records remain protected unless
  the user explicitly includes or replaces them.
* Expanded core, package, resource, UDMF, rendering, Smart Sector, command,
  dialog, persistence, large-coordinate, and Undo/Redo regression coverage.
* The release matrix builds and tests Linux x86_64/arm64, Windows x86/x86_64,
  and macOS Intel/Apple-silicon packages and publishes matching SHA-256
  checksums.
