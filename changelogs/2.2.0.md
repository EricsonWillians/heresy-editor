# Heresy Editor 2.2.0

This release completes the first BiasedDoom-focused project workflow roadmap.

## Project authoring

* Added preservation-safe WAD and PK3 projects with full-IWAD, single-map, and
  validated custom campaign layouts.
* Added Campaign Navigator operations for opening, creating, duplicating,
  renaming, and deleting maps.
* Added a bounded multi-map document cache that retains independent undo and
  unsaved state without evicting dirty maps.

## Saving and recovery

* Added atomic Save Project and Save All transactions for every dirty resident
  map and the project metadata.
* Added rotating, validated recovery snapshots that never modify the project
  package and remain dirty until deliberately saved.
* Added portable `.heresy` session sidecars for active-map, navigator, recent
  project, and relocatable IWAD restoration.

## BiasedDoom compatibility

* Added a dedicated `biaseddoom` profile derived from the shared ZDoom
  definitions, with cross-platform executable discovery and launch coverage.
* Audited BiasedDoom 4.15.7 against its exact GZDoom merge base. No fork-only
  DoomEdNums, action specials, or UDMF namespace were found.
* Preserved extended linedef, sidedef, and sector UDMF properties through
  editing and round trips without changing Doom or Hexen binary output.
* Exercised dirty Doom, Hexen, and UDMF maps through the complete save,
  node-build, argument, and Test in Game launch path.
* Added a pinned release contract plus weekly detection of published-release
  or map-metadata compatibility drift.

## Distribution

* Linux x86_64 and arm64, Windows x86 and x86_64, and macOS x86_64 and arm64
  packages are built and tested by one release workflow.
* Every downloadable package has a matching SHA-256 checksum. macOS packages
  are ad-hoc signed and are not Apple-notarized.
